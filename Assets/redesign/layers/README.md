# Yank app icon — Icon Composer source

Flat, effect-free layers for building the **real** Liquid Glass app icon in
Apple's **Icon Composer** (free, ships with Xcode 16+). The composited SVGs in
`../yank-mark-dark.svg` / `-light.svg` are the *web* marks; this is the *app* icon.

Why flat? Apple's material is generated by the system — you author flat shapes
and Icon Composer adds translucency, specular highlights, frostiness, and
per-layer shadow. Baking your own gradients/bevels fights it (WWDC25 “Create
icons with Icon Composer”, session 361).

## Layers (back → front)

| File | Group / role | Dark fill | Light fill (variant) |
|------|--------------|-----------|----------------------|
| `01-background.svg` | Background (full-bleed, no mask) | `#1C1C1E` | System Light |
| `02-card-back.svg`  | Back card — history beneath | `#FFFFFF` | graphite e.g. `#3A3A3F` |
| `03-card-front.svg` | Front card + snippet lines | `#FFFFFF` | graphite card, light lines |
| `04-arrow.svg`      | The amber “yank” (front) | `#FBBF24` | `#FBBF24` |

The canvas is 1024×1024. **Do not** add the rounded-rectangle mask — the system
applies it. Shapes already sit inside the safe central area, corners are rounded,
and the arrow is bold so it survives small sizes.

## Build it

1. Open **Icon Composer** → New. Drag the four SVGs in, ordered 01→04 (back→front).
2. Put them in **groups by depth** (≤4 groups). A clean split: `01` = Background;
   `02`+`03` = the cards group; `04` = the arrow group.
3. Select the card + arrow groups and **toggle Liquid Glass on**. Leave specular
   on; choose **Neutral** shadow (or **Chromatic** for a warmer amber spill).
4. Author the three appearances Apple needs — the system derives the rest:
   - **Default (light):** set Background to *System Light*; give the two cards a
     **graphite fill variant** so they read on the light ground (white cards
     vanish on white). Arrow stays amber.
   - **Dark:** Background *System Dark* (or the `#1C1C1E` layer); cards white;
     arrow amber.
   - **Mono:** make the **front card full white** (the recognizable element);
     the amber maps to grey. Tune for contrast — the in-app Mono preview reads
     lighter than the device, so check on hardware.
5. Reduce the card overlap if the reflective edge between them muddies (the
   Photos-icon lesson). If the arrowhead goes “pillowy”, turn specular **off**
   for the arrow group (the Calendar fix).
6. **Export** the `.icon`, add it to `Yank.xcodeproj` (and the iOS target), and
   set it as the app icon. Verify all appearances on a real macOS 26 / iOS 26
   device across a few wallpapers.

## Menu-bar glyph (separate)

The menu bar uses the standalone color mark from `Assets/yank-glyph.svg`: white
front card, gray back card, amber yank arrow. `Assets.xcassets/BrandGlyph.imageset`
keeps original rendering so the mark matches the launcher icon instead of being
system-tinted.
