# Yank Support

Yank support is provided through this public GitHub repository.

## Get help

Before reporting a problem, install the latest available version and search the
[existing issues](https://github.com/The-PatientZero/yank/issues) for a matching report.

For general support, questions, or bug reports, open a
[new GitHub issue](https://github.com/The-PatientZero/yank/issues/new). Include:

- whether you are using macOS, iPhone, or iPad;
- the Yank version and operating-system version;
- what you expected to happen and what happened instead; and
- concise steps that reproduce the problem.

Do not include clipboard contents, screenshots containing private information, account
details, or other sensitive data in a public issue.

## iPhone and iPad help

- **Save clipboard content:** Run Yank's **Save Clipboard** action from Shortcuts, or share
  selected text, a link, or an image to **Save to Yank**. iOS does not allow Yank to monitor
  the clipboard automatically in the background.
- **Enable the keyboard:** Open **Settings > General > Keyboard > Keyboards > Add New
  Keyboard**, then select **Yank Keyboard**. Full Access is not required and should remain
  disabled.
- **Use shared content:** Open Yank after using the share extension so the app can import the
  item into history.
- **Use iCloud sync:** Enable iCloud Sync in Yank on devices signed in to the same Apple
  Account. Sync is optional and off by default.

## Privacy and security

Read the [Privacy Policy](PRIVACY.md) for information about local storage, optional iCloud
sync, extensions, on-device intelligence, permissions, and deletion controls.

Security vulnerabilities must not be posted in a public issue. Follow the private reporting
instructions in the [Security Policy](SECURITY.md) instead.
